A Xojo web project trying to come up with a generic way of turning any data (well, a dictionary or a rowset basically) into a container displaying the data. The project would just look at the data and infer what control should be used to display it. 
You also can tell it what control to use. The code tries (not too hard though) to properly position those controls onto the container.

Feel free to improve or use as you like.
